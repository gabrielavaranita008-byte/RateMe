# RateMe

RateMe is a modern review platform where users can explore categories, discover products and services, and share opinions through interactive reviews.

## Features

* Interactive category system
* Product and service reviews
* Search functionality
* Animated and responsive UI
* Login/Register system using Local Storage
* Review publishing and community interaction
* Dynamic category detail pages

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage API
* Responsive Design

## Project Organization

The project was developed using the Agile Scrum methodology. Team activities were planned in sprints, while tasks and progress tracking were managed using Trello and Notion.

## Project Goal

The goal of the application is to create a modern and accessible platform where users can find and publish real reviews about different products, services, and locations in order to support informed decision-making.
